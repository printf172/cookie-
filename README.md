# 网站Cookie获取器

## 软件简介

网站Cookie获取器是一款Chrome浏览器扩展，专为需要获取和管理网站Cookie信息的用户设计。它支持所有网站，并能够将Cookie变化实时传输到指定的后台服务器。

## 功能特点

- **自动检测和获取Cookie**：无需手动操作，自动获取当前网站的Cookie信息。
- **区分Cookie类型**：轻松区分第一方和第三方Cookie。
- **详细Cookie属性显示**：查看Cookie的SameSite和Secure属性。
- **便捷的复制功能**：支持单个或所有Cookie的复制，格式为key=value。
- **手动刷新**：随时手动刷新以获取最新的Cookie。
- **适应最新政策**：完全适应Chrome最新的Cookie政策。
- **实时监控**：在网页控制台中实时监控HTTP请求中的Cookie变化。
- **后台传输**：支持将Cookie数据传输到自定义后台，提供可配置的传输选项。

## 安装方法

1. 下载或克隆本仓库到本地。
2. 打开Chrome浏览器，进入扩展管理页面：`chrome://extensions/`。
3. 开启右上角的"开发者模式"。
4. 点击"加载已解压的扩展程序"，选择本仓库所在的文件夹。
5. 安装完成后，扩展图标将显示在浏览器工具栏中。

## 使用说明

1. 访问任意网站，扩展会自动检测并获取当前网站的Cookie。
2. 点击扩展图标，查看获取到的Cookie信息。
3. 使用"刷新Cookie"按钮可以手动更新Cookie。
4. 使用"复制所有Cookie"按钮可以将所有Cookie复制到剪贴板。
5. 在网页中按F12打开开发者工具，在控制台中也可以看到Cookie信息。
6. 点击"配置"按钮可以设置后台传输选项。

## 后台传输配置

本扩展支持将Cookie数据实时传输到指定的后台服务器：

1. 点击扩展图标，然后点击"配置"按钮
2. 在配置页面中，启用"后台传输"选项
3. 填写后台接口地址（例如：https://example.com/api/cookies）
4. 选择请求方法（POST或PUT）
5. 根据需要配置自定义请求头（JSON格式）
6. 设置数据格式，使用{domain}和{cookies}作为占位符
7. 点击"测试连接"按钮验证配置是否正确
8. 点击"保存配置"按钮保存设置

配置保存后，当网站的Cookie发生变化时（包括HTTP请求过程中的变化），扩展会自动将最新的Cookie数据发送到指定的后台地址。

## 查看日志

本扩展的日志会显示在不同的位置：

1. **扩展后台日志**：
   - 在扩展管理页面(chrome://extensions/)中找到"网站Cookie获取器"
   - 点击"Service Worker"链接或"检查视图"中的"Service Worker"选项
   - 在打开的DevTools窗口中查看控制台

2. **弹出窗口日志**：
   - 点击扩展图标，打开弹出窗口
   - 在弹出窗口上右键点击，选择"检查"
   - 在打开的DevTools窗口中查看控制台

3. **网页控制台日志**：
   - 在当前网站页面上按F12打开开发者工具
   - 切换到"控制台"标签
   - 查看带有"Cookie获取器"前缀的日志
   - 在控制台中点击带有[复制]标记的行可以复制单个Cookie

## 关于Chrome Cookie政策

Chrome浏览器正在逐步淘汰第三方Cookie，这可能会影响某些网站的功能。本扩展已对Cookie进行分类，以帮助您了解哪些Cookie可能在未来受到影响：

- **第一方Cookie**：由您直接访问的网站设置，将继续正常工作
- **第三方Cookie**：由其他域设置，将在未来的Chrome版本中被限制

## 故障排除

如果您遇到以下问题，请尝试相应的解决方法：

### 1. "Could not establish connection. Receiving end does not exist."

这个错误通常出现在控制台中，表示扩展的不同部分之间通信出现问题。解决方法：

- 重新加载扩展：在扩展管理页面点击扩展的刷新图标
- 重启浏览器
- 确保页面已完全加载

### 2. "Service Worker (无效)"

如果在扩展管理页面看到"Service Worker (无效)"的提示：

- 点击扩展卡片上的"错误"按钮，查看具体错误信息
- 重新加载扩展：点击扩展卡片右下角的刷新图标
- 重启浏览器

### 3. 无法获取Cookie

如果扩展无法获取Cookie，请尝试：

- 确保您已登录网站（如果需要）
- 刷新网页
- 点击扩展弹出窗口中的"刷新Cookie"按钮
- 检查浏览器的Cookie设置，确保没有阻止Cookie

### 4. 无法在浏览器控制台看到日志

如果您在浏览器的控制台中看不到日志：

- 确保您已打开网站
- 在控制台过滤器中输入"Cookie"以筛选相关日志
- 刷新页面，等待content script加载

### 5. 后台传输失败

如果Cookie数据无法成功传输到后台：

- 检查后台接口地址是否正确
- 确认后台服务器是否正常运行
- 验证自定义请求头和数据格式是否为有效的JSON
- 查看扩展后台日志中的错误信息
- 使用"测试连接"按钮验证配置

## 隐私说明

本扩展获取当前网站的Cookie信息，并可能将这些数据发送到您配置的后台服务器。除此之外，扩展不会收集或发送您的个人数据到任何其他外部服务器。所有配置数据仅存储在您的浏览器本地。
